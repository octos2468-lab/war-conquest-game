## 📋 Common Questions

### "What is a commit?"
A commit is a snapshot of your project at a specific point in time. It's like a checkpoint in a video game - you can always go back to it. Each commit includes:
- The changes you made
- A message describing what you did
- A timestamp
- Who made the changes

See [Git Basics](git-basics-for-beginners.md) for more details.

### "How do I work with AI if I don't understand code?"
You don't need to understand code! You need to:
1. Describe what you want clearly
2. Test what the AI builds
3. Give feedback on how it works

See [Working with AI Agents](working-with-ai-agents.md) for detailed guidance.

### "What terms do I need to know?"
Start with these basics:
- **Commit**: A save point for your project
- **Repository (Repo)**: The folder containing your project
- **Branch**: A separate timeline for testing features
- **Push**: Upload changes to GitHub
- **Pull**: Download changes from GitHub

See [Technical Glossary](technical-glossary.md) for complete definitions.

### "Where do I start?"
1. Read [Git Basics](git-basics-for-beginners.md) (20 minutes)
2. Skim [Working with AI Agents](working-with-ai-agents.md) (30 minutes)
3. Review your [Game Design](game-design.md) (10 minutes)
4. Make your first request to an AI agent (5 minutes)
5. Test what they build (10 minutes)
6. Celebrate your first step! 🎉

## 📝 Development Best Practices

### 1. Work in Small Steps
- Build one feature at a time
- Test after each addition
- Don't try to do everything at once

### 2. Test Constantly
- Play your game after each change
- Make sure old features still work
- Find bugs early when they're easy to fix

### 3. Commit Frequently
- Commit after each working feature
- Write clear commit messages
- Think of commits as save points

### 4. Keep Your Design Doc Updated
- Document new ideas
- Update when plans change
- Keep AI agents in sync with your vision

### 5. Ask Questions
- No question is too basic
- Ask for explanations in simple terms
- Use the glossary as a reference

## 🤝 Working with AI Agents

### Your Communication Style Should Be:

**Clear:**
> "Create a tower that shoots arrows at enemies within 150 pixels, dealing 10 damage per hit, firing once per second"

Not:
> "Make a tower thing"

**Specific:**
> "The health bar should be green above 50%, yellow between 25-50%, and red below 25%"

Not:
> "Add a health bar"

**Structured:**
```
"I want to add [feature]

It should:
- [behavior 1]
- [behavior 2]
- [behavior 3]

Visual details:
- [appearance]

Start with [first step]"
```

See [Working with AI Agents](working-with-ai-agents.md) for many more examples.
