🏰 PROJECT SKELETON – Working Title

1️⃣ Core Concept



Genre: Hybrid Strategy RPG

Core Loop Per Level:



Castle Defense (Tower Defense)



Open War (Lane Battle)



Castle Infiltration (Turn-Based Boss)



Player Fantasy:

Command armies → Win war → Personally defeat enemy leader.



2️⃣ Pillars (What This Game Is About)



Keep this short and sacred.



Strategic escalation



Power growth over campaign



Dark fantasy war atmosphere



No city micromanagement



No Civ-style economy sim



If a feature doesn’t support these pillars, cut it.



3️⃣ Level Structure Template



Every level follows this structure:



Phase 1 – Defense



Player defends castle



X waves



Can build limited towers



Survive to advance



Phase 2 – War



Side-scrolling lane battle



Spawn units



Destroy enemy outer wall



Phase 3 – Duel



Turn-based boss fight



Unique boss abilities



Win = conquer territory



4️⃣ Combat System Outlines

🏹 Tower Defense System



Core Mechanics



Fixed tower nodes



Auto-target nearest enemy



Upgrade tiers (optional later)



Gold earned from kills



Keep V1 simple:



2 tower types max



No branching upgrades



⚔️ Lane War System



Core Mechanics



Gold income over time



Spawn cooldowns



Units auto-walk + auto-attack



Base HP bar



V1 Limit:



2 unit types



No hero yet



No spells yet



🧠 Turn-Based Duel System



Core Mechanics



Player HP / Energy



3 abilities



Status effects (later)



Enemy AI chooses ability



V1 Limit:



3 abilities



1 status effect max



Simple boss pattern



5️⃣ Campaign Structure



World Map:



Territories connected



Each territory = 1 level



Beating leader unlocks adjacent region



Optional Later:



Faction types



Different boss archetypes



6️⃣ Player Progression



Between levels player can:



Unlock new unit



Unlock new tower



Unlock new ability



Increase base HP



No resource farming.

No building farms.

No Civ systems.



7️⃣ MVP (Minimum Viable Game)



Your first playable version must ONLY include:



1 level



1 tower type



2 unit types



1 boss



No world map



No upgrades



No polish



If you can finish that, you win.
